# Bebragram

Telegram с поддержкой сети Tor через WebTunnel на базе NagramX.

Скачать APK: [Bebragram 12.10.0 (1269)](https://github.com/eqsit/bebragram/releases/tag/v12.10.0-1269). Для современных телефонов выбирайте **arm64-v8a**, для остальных поддерживаемых архитектур — **Universal**. Обновление устанавливается поверх предыдущего Bebragram с сохранением данных; контрольные суммы приложены к релизу.

Чтобы подключиться, откройте **Настройки → Сеть Tor** и включите Tor-прокси. Приложение загрузит мосты с GitHub, проверит доступность их адресов и подключит Telegram через Tor. Если мост перестанет работать, приложение попробует обновить список и подключиться снова.

Доступен только WebTunnel: Snowflake удалён из интерфейса и нативной библиотеки. При обновлении старый выбор транспорта автоматически заменяется на WebTunnel.

Автозапуск включён по умолчанию: если Tor-прокси включён, он запускается при следующем открытии приложения. Переключатель автозапуска можно выключить.

При включённом VPN Tor ждёт его отключения. Это поведение меняется переключателем в разделе прокси.

В настройках сети Tor есть кнопка **Перезапустить Tor**. После смены сети или выключения VPN приложение обрабатывает переход с задержкой 250 мс и перепроверяет автоматические мосты текущего сеанса вместе с запасными кандидатами на новой сети. Проверка всей группы ограничена четырьмя секундами и завершается сразу после двух успешных ответов; если доступных кандидатов нет, загружается свежий список. Введённые вручную мосты сохраняются. При потере цепочек сначала проверяются сохранённые запасные кандидаты. Автообновление мостов сохраняет рабочее соединение.

Журнал Tor доступен в приложении и через ADB: `adb logcat -v threadtime -s BebragramTor:I '*:S'`. В журнале есть время получения мостов, этапы bootstrap и длительность подключения; при ожидании bootstrap сообщения появляются каждые пять секунд.

При подборе проверяются до 12 адресов и сохраняются до шести мостов с разными доменами. TLS-проверки выполняются при подборе и восстановлении. Загрузка консенсуса и дескрипторов получает 60 секунд без активности; получение данных продлевает ожидание, общий предел bootstrap — четыре минуты. Краткая потеря цепочки получает 30 секунд для восстановления средствами Tor. После неудачных попыток повторный подбор продолжается с паузой от 30 секунд до пяти минут; выключение Tor отменяет его. Проверка работающей цепочки читает локальный control-интерфейс раз в 15 секунд, при покое Tor — раз в 30 секунд.

Готовые цепочки Conflux учитываются при запуске и проверке состояния, чтобы не оставаться на Starting после 100%. Кнопка **Проверить соединение Telegram** измеряет отклик Telegram через выбранную цепочку Tor только по запросу пользователя; это отдельный показатель от скорости рукопожатия WebTunnel. Результат также попадает в журнал. Запасные мосты сохраняются из обоих источников, а не только из последнего списка.

Статус отдельно показывает готовность Tor и состояние соединения текущего аккаунта Telegram (подключение, обновление или подключено). Изменения состояния Telegram фиксируются в журнале вместе с временем после включения прокси.

Без включённого Tor-прокси Telegram работает как обычно. Для сборки из исходников нужны Android SDK, ключ подписи и действительные Telegram API ID и hash, Go и NDK 28.2.13676358 для транспортов ([подробнее](Tools/tor-transport/README.md)).

Исходный проект: [NagramX](https://github.com/risin42/NagramX). Список мостов: [Tor Bridges Collector](https://github.com/Delta-Kronecker/Tor-Bridges-Collector). Лицензия: [GPLv3](LICENSE).
