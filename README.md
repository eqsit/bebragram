# Bebragram

Telegram с поддержкой сети Tor через WebTunnel на базе NagramX.

Чтобы подключиться, откройте **Настройки → Сеть Tor** и включите Tor-прокси. Приложение загрузит мосты с GitHub, проверит доступность их адресов и подключит Telegram через Tor. Если мост перестанет работать, приложение попробует обновить список и подключиться снова.

Доступен только WebTunnel: Snowflake удалён из интерфейса и нативной библиотеки. При обновлении старый выбор транспорта автоматически заменяется на WebTunnel.

Автозапуск включён по умолчанию: если Tor-прокси включён, он запускается при следующем открытии приложения. Переключатель автозапуска можно выключить.

При включённом VPN Tor ждёт его отключения. Это поведение меняется переключателем в разделе прокси.

Без включённого Tor-прокси Telegram работает как обычно. Для сборки из исходников нужны Android SDK, ключ подписи и действительные Telegram API ID и hash, Go и NDK 28.2.13676358 для транспортов ([подробнее](Tools/tor-transport/README.md)).

Исходный проект: [NagramX](https://github.com/risin42/NagramX). Список мостов: [Tor Bridges Collector](https://github.com/Delta-Kronecker/Tor-Bridges-Collector). Лицензия: [GPLv3](LICENSE).
